### **Python Programming Question Paper**  

1. What will be the output of the following code?  
   ```python
   print(10 + "20")
   ```  

2. Identify the error in this code:  
   ```python
   x = 5  
   y = x + z  
   print(y)
   ```  

3. What will be the output of this code?  
   ```python
   print(2 * 3 ** 3)
   ```  

4. Predict the output:  
   ```python
   x = "5"  
   y = 2  
   print(x * y)
   ```  

5. Identify the data type of the output:  
   ```python
   a = 10.5  
   b = 2  
   c = a // b  
   print(type(c))
   ```  

6. What will be the output of this comparison?  
   ```python
   print(10 == 10.0)  
   print(10 is 10.0)
   ```  

7. Find the output:  
   ```python
   a = True + 2  
   b = False + 5  
   print(a, b)
   ```  

8. Write a program to check if a number is positive, negative, or zero.  

9. What will be the output?  
   ```python
   x = 10  
   if x > 5:  
       print("Greater")  
   elif x > 8:  
       print("Larger")  
   else:  
       print("Smaller")
   ```  

10. Write a program using a `for` loop to print all even numbers from 1 to 20.  

11. What is the output of the following code?  
    ```python
    x = 1  
    while x < 5:  
        print(x)  
        x -= 1  
    ```  

12. Identify the error:  
    ```python
    for i in range(5, 1, 1):  
        print(i)
    ```  

13. What will be the output?  
    ```python
    for i in range(3):  
        for j in range(2):  
            print(i, j)
    ```  

14. What will be the output?  
    ```python
    s = "hello"  
    print(s[::-1])
    ```  

15. Identify the error:  
    ```python
    lst = [1, 2, 3]  
    print(lst[3])
    ```  

16. Write a Python program to find the length of a given list without using `len()`.  

17. Write a function to return the factorial of a given number.  

18. What will be the output?  
    ```python
    def func(a, b=2, c=3):  
        return a + b + c  
      
    print(func(1))
    ```  

19. Identify the error:  
    ```python
    def add(a, b):  
        return a + b  
      
    print(add(5))
    ```  

20. Write a function to check if a given string is a palindrome.
